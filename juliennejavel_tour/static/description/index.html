🎯 Julienne Javel Tours

Visites guidées interactives pour les modules Julienne Javel

🚀
Démarrage Rapide

Accès direct depuis le menu BET avec le bouton "Démo rapide" pour une découverte immédiate des fonctionnalités.

🎭
Tours Personnalisés

Plusieurs niveaux de visite : simple (2 min) ou avancé (5 min) avec explications détaillées et navigation guidée.

🎨
Interface Élégante

Styles personnalisés avec animations fluides, design responsive et messages de félicitation interactifs.

⚙️
Facilement Extensible

Architecture modulaire permettant d'ajouter facilement de nouveaux tours pour d'autres modules Julienne Javel.

Comment utiliser ?

1
Accès rapide

Menu BET → 🚀 Démo rapide

2
Ou sélection

BET → Configuration → 🎯 Visite guidée

3
Suivez le guide

Laissez-vous guider par les explications interactives

Prérequis

Ce module nécessite le module juliennejavel_base pour fonctionner. Il utilise le framework de tours natif d'Odoo 16.0.

Développé pour Julienne Javel | Compatible Odoo 16.0
